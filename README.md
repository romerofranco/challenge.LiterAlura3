# LiterAlura - Catálogo de Libros

## Descripción
LiterAlura es un catálogo de libros desarrollado en Java con Spring Boot que permite buscar y registrar libros mediante la API Gutendex, almacenando la información en una base de datos PostgreSQL.

## Funcionalidades
- Buscar libro por título
- Listar libros registrados
- Listar autores registrados
- Listar autores vivos en un determinado año
- Listar libros por idioma

## Tecnologías utilizadas
- Java 25
- Spring Boot
- Spring Data JPA
- PostgreSQL
- API Gutendex

## Cómo ejecutar el proyecto
1. Clonar el repositorio
2. Crear una base de datos PostgreSQL llamada `literalura`
3. Configurar las credenciales en `application.properties`
4. Ejecutar el proyecto desde IntelliJ IDEA
